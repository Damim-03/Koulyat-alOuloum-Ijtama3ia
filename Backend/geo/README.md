# قواعد العناوين (geo)

ملفّان يضعان كلّ عنوان IP في سجلّ العمليات على الخريطة — البلد والولاية والمدينة —
ويسمّيان شبكته (اتصالات الجزائر، Djezzy، Mobilis…). يُقرآن على الخادم نفسه:
عناوين المستخدمين لا تُرسل إلى أيّ جهة (`src/core/geo/geo.ts`).

لا يُرفعان إلى git (حجمهما نحو 140MB). يُنزَّلان من DB-IP، بلا حساب:

```bash
cd Backend/geo
M=$(date +%Y-%m)   # إصدار الشهر الحالي
curl -fL "https://download.db-ip.com/free/dbip-city-lite-$M.mmdb.gz" | gunzip > "dbip-city-lite-$M.mmdb"
curl -fL "https://download.db-ip.com/free/dbip-asn-lite-$M.mmdb.gz"  | gunzip > "dbip-asn-lite-$M.mmdb"
```

- **يُقرأ الأحدث من كلّ نوع** (الاسم يحمل الشهر): ضع ملفّ الشهر الجديد بجانب القديم، أعد
  تشغيل الخادم، ثمّ احذف القديم. تُحدَّث القواعد كلّ شهر، ودقّتها تقلّ مع الوقت.
- **بلا الملفّين** يعمل كلّ شيء كما هو، والسجلّ بلا أماكن.
- **في Docker** يدخلان الصورة إن كانا هنا يوم البناء (`docker compose up -d --build`).
- **الصفوف القديمة**: `npm run backfill:geo` يضع المكان على ما كُتب قبل وضع الملفّين.
- مكانٌ آخر للملفّين: `GEOIP_DIR` في `.env`؛ وقيمةٌ فارغة تُطفئ الميزة.

**الدقّة:** البلد دقيق، والمدينة تقريبية — شبكات الهاتف تظهر غالباً بمدينة معدّات المشغّل
(الجزائر العاصمة) لا بمكان الشخص. والمشغّل يقول ما لا تقوله المدينة.
